WAF BunkerWeb
LOG-001 · 2024
WAF Bypass Techniques in Open-Source Environments
Documented findings from internal security testing of BunkerWeb — an open-source WAF — during beta testing cycles. Identified edge cases in rule parsing and evasion patterns that bypassed core protections under specific HTTP configurations.

Tools & Techniques

ModSecurity Burp Suite cURL Manual HTTP Fuzzing

Findings

  • Header injection bypassing input sanitization rules
  • Chunked encoding edge cases escaping body inspection
  • False-negative patterns in custom ModSecurity ruleset
  • Contributed fixes merged into upstream release

Recommendations

  • Normalize HTTP transfer-encoding before rule inspection to close chunked-encoding gaps.
  • Add regression tests for header-injection payloads in the WAF's CI pipeline.
  • Periodically re-run fuzz testing after ruleset updates to catch newly introduced blind spots.

LOG-002 · 2024
Threat Detection Patterns with Elastic SIEM
Homelab research using Elastic Stack to simulate and detect real-world attack patterns. Designed custom detection rules, dashboards, and alert pipelines to surface IOCs from Windows and Linux event logs.

Tools & Techniques

Elastic Stack Winlogbeat Sysmon KQL

Findings

  • Brute-force SSH pattern detection via Winlogbeat
  • Lateral movement signatures in internal network traffic
  • Custom KQL queries for Sysmon event correlation
  • Alert tuning to reduce false positives by ~60%

Recommendations

  • Baseline "normal" login and process behavior before tuning alert thresholds.
  • Correlate Sysmon process-creation events with network telemetry to catch lateral movement earlier.
  • Review and prune noisy detection rules on a recurring schedule to keep signal-to-noise high.

Network pfSense
LOG-003 · 2024
VLAN Segmentation & Firewall Rule Hardening
Lab exercise modeling enterprise network segmentation using pfSense. Focused on isolating traffic between trusted, DMZ, and untrusted zones, with Wireshark packet captures validating rule enforcement across segments.

Tools & Techniques

pfSense Wireshark Nmap VLAN Trunking

Findings

  • VLAN hopping mitigated via strict trunk port policy
  • DNS-based exfiltration attempts captured and blocked
  • Firewall state table analysis under simulated DDoS load
  • Inter-VLAN routing locked down with ACL precision

Recommendations

  • Disable native VLAN usage on trunk ports and force explicit tagging.
  • Log and alert on outbound DNS queries that deviate from expected resolver traffic.
  • Set firewall state-table limits per zone to reduce blast radius during flood conditions.

Python Recon
LOG-005 · 2023
Building 4SCAN — TCP Port Scanner from Scratch
Dev log for 4SCAN, a custom Python TCP port scanner. Documented the architecture decisions, threading model, timeout handling, and socket programming concepts that went into building a reliable scanning tool from the ground up.

Tools & Techniques

Python Sockets ThreadPoolExecutor CIDR Parsing

Findings

  • Socket-level TCP handshake analysis and banner grabbing
  • Thread pool tuning for optimal speed vs accuracy
  • Timeout edge cases causing false closed-port reads
  • CIDR range parsing added in v1.2 iteration

Recommendations

  • Use adaptive timeouts based on observed round-trip latency instead of a fixed value.
  • Cap concurrent threads relative to target host count to avoid self-inflicted false negatives.
  • Add retry-on-timeout logic before marking a port closed to cut down false negatives further.
